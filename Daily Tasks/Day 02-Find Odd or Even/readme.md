# Odd or Even Number

This task is a simple JavaScript program used to check whether a given number is **Odd or Even**.

## 🛠️ Technologies Used

* HTML5
* JavaScript

## 📂 Files

* `index.html` – Contains the HTML structure and input interface.
* `script.js` – Contains the JavaScript logic to check whether the number is odd or even.
* `Output/` – Contains the output screenshot of the task.

## 🎯 Objective

The objective of this task is to practice JavaScript **conditional statements** and understand how to determine whether a number is odd or even.

## ⚙️ How It Works

1. Enter a number in the input field.
2. The JavaScript program checks the given number.
3. It uses the **modulus (`%`) operator** to find the remainder.
4. If the remainder is `0`, the number is **Even**.
5. Otherwise, the number is **Odd**.
6. The result is displayed on the webpage.
