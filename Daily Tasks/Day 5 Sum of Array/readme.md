# Day 5 - Sum of Array

## 📌 About the Project

This project is a simple JavaScript program that calculates the **sum of all elements in an array**.

An array is created with a set of numbers, and JavaScript is used to access each element of the array and add all the values together. The final sum is then displayed as the output.

This task helps in understanding how arrays and loops can be used together in JavaScript.

## 🎯 Objective

The main objective of this task is to practice working with arrays and calculate the total of all the numbers stored in an array.

Through this task, the following concepts are practiced:

* Creating an array
* Accessing array elements
* Using a `for` loop
* Using array length
* Adding multiple values
* Storing and displaying the final result

## 🛠️ Technologies Used

* **HTML5** – Used to create the basic webpage structure.
* **JavaScript** – Used to create the array, calculate the sum, and display the result.

## ⚙️ How the Program Works

1. An array containing multiple numbers is created.
2. A variable is initialized to store the total sum.
3. A `for` loop is used to go through each element of the array.
4. Each array element is added to the sum.
5. After the loop finishes, the total sum is displayed on the webpage.

## 💡 Example

Consider the following array:

```text
[5, 10, 15, 20]
```

The program adds all the values:

```text
5 + 10 + 15 + 20 = 50
```

Therefore, the final output is:

```text
50
```
