# Task 1 – First Repeating Character

## 📌 Description
This JavaScript program finds the first repeating character in a string entered by the user.

The program compares each character with the following characters using nested `for` loops. When a repeating character is found, it displays the character on the webpage.

## 🛠️ Technologies Used
- HTML5
- JavaScript

## 📂 Project Structure
```text
Task 1-Repeating Character/
├── index.html
├── script.js
├── README.md

    └── output.png
```

## ⚙️ How It Works
1. The user enters a string in the input field.
2. The program uses nested `for` loops to compare characters.
3. When a repeating character is found, the loop stops.
4. The first repeating character is displayed on the webpage.
5. If no repeating character is found, a message is displayed.

## 💻 Example

**Input:**
```text
programming
```

**Output:**
```text
First Repeating Character: r
```
