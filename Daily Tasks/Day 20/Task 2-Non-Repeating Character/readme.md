# Task 2 – First Non-Repeating Character

## 📌 Description
This JavaScript program finds the first non-repeating character in a string entered by the user.

A non-repeating character is a character that appears only once in the given string. The program uses nested `for` loops to count the occurrences of each character and displays the first character that appears only once.

## 🛠️ Technologies Used
- HTML5
- JavaScript

## 📂 Project Structure
```text
Task 2-Non-Repeating Character/

```

## ⚙️ How It Works
1. The user enters a string in the input field.
2. The program selects each character one by one.
3. Nested `for` loops count how many times each character appears.
4. If a character appears only once, it is selected as the first non-repeating character.
5. The result is displayed on the webpage.
6. If no non-repeating character is found, an appropriate message is displayed.

## 💻 Example

**Input:**
```text
aabbcddee
```

**Output:**
```text
First Non-Repeating Character: c
```
