# Task 2 – Reverse

## 📌 Description

This JavaScript program reverses a given string using a loop.

### Example

```text
Input: hello
Output: olleh
```

## 🛠️ Technologies Used

* HTML
* JavaScript

## 📂 Files

* `index.html` – HTML file for the webpage
* `script.js` – JavaScript file containing the reverse logic
* `Output` – Contains the output screenshot

## ⚙️ How It Works

1. A string is given as input.
2. The JavaScript program starts from the last character of the string.
3. A loop is used to read each character in reverse order.
4. The characters are added together to form the reversed string.
5. The reversed string is displayed as the output.
