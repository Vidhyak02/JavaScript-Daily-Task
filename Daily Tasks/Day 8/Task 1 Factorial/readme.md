# Task 1 – Factorial

## 📌 Description

This JavaScript program calculates the **factorial of a given number** using a loop.

The factorial of a number `n` is the product of all positive integers from `1` to `n`.

### Example

```text
5! = 5 × 4 × 3 × 2 × 1
5! = 120
```

## 🛠️ Technologies Used

* HTML
* JavaScript

## 📂 Files

* `index.html` – HTML file for the webpage
* `script.js` – JavaScript file containing the factorial logic
* `Output` – Contains the output screenshot

## ⚙️ How It Works

1. A number is given as input.
2. The JavaScript program initializes the factorial value as `1`.
3. A loop is used to multiply the numbers from `1` to the given number.
4. The calculated factorial is displayed as the output.
