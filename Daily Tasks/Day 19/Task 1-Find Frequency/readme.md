# Task 1 – Find Frequency

## 📌 Description
This JavaScript program finds the frequency of each character in a string entered by the user. It counts how many times each character appears and displays the result.

## 🛠️ Technologies Used
- HTML5
- JavaScript

## ⚙️ Features
- Accepts a string from the user.
- Counts the occurrence of each character.
- Displays the frequency of each character.
- Uses loops and conditional statements.

## 💻 Sample Input
```text
banana
```

## ✅ Sample Output
```text
b : 1
a : 3
n : 2
```
