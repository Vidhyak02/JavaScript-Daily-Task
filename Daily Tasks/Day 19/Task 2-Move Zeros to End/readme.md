# Task 2 – Move Zeros to End

## 📌 Description
This JavaScript program moves all zeros in an array to the end while maintaining the original order of the non-zero elements.

## 🛠️ Technologies Used
- HTML5
- JavaScript

## ⚙️ Features
- Accepts numbers from the user.
- Identifies zeros in the array.
- Moves all zeros to the end.
- Preserves the order of non-zero elements.
- Displays the modified array.

## 💻 Sample Input
```text
0, 5, 0, 3, 8, 0, 2
```

## ✅ Sample Output
```text
5, 3, 8, 2, 0, 0, 0
```
