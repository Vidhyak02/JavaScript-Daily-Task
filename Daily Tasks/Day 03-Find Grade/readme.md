# Day 3 – Grade

This is my **Day 3 JavaScript Daily Task**, created to practice using JavaScript conditions to calculate a grade based on marks.

## 📌 Task Description

The program takes the student's marks as input and determines the corresponding grade using JavaScript conditional statements.

## 🛠️ Technologies Used

* HTML5
* JavaScript

## 📂 Project Structure

```text
Day 3 Grade/
│
├── index.html
├── script.js
└── Output/
    └── output.png
```

## ⚙️ How It Works

1. Enter the marks.
2. JavaScript checks the marks using conditional statements.
3. The appropriate grade is displayed as the output.

## 💻 Files

* **index.html** – Contains the webpage structure and input elements.
* **script.js** – Contains the JavaScript logic for calculating the grade.
* **Output** – Contains the screenshot of the program output.
