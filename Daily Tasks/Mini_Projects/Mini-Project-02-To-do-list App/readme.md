# 📝 Mini Project 02 – To-Do List App

## 📌 About the Project

The To-Do List App is a simple task management web application developed using HTML, CSS, and JavaScript. It allows users to add, manage, and organize their daily tasks in one place.

The main objective of this project is to practice JavaScript DOM manipulation, event handling, and interactive web development.

## ✨ Features

- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Manage daily activities easily.
- Interactive and user-friendly interface.
- Dynamically update the task list.

## 🛠️ Technologies Used

- **HTML5** – Creates the application structure.
- **CSS3** – Styles the user interface.
- **JavaScript (ES6+)** – Implements task management functionality.
- **DOM Manipulation** – Dynamically updates task elements.
- **Event Handling** – Handles user interactions.

## ⚙️ How It Works

1. Enter a task in the input field.
2. Click the Add button to add the task.
3. View the added task in the task list.
4. Mark a task as completed when finished.
5. Delete tasks that are no longer needed.
