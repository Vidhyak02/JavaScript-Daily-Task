# 🌦️ Mini Project 01 – Weather App

## 📌 About the Project

The Weather App is a web-based application developed using HTML, CSS, and JavaScript. It allows users to search for a city and view its current weather information by fetching data from an external Weather API.

This project focuses on practical API integration, asynchronous JavaScript, and dynamic content rendering.

## ✨ Features

- Search weather information by city name.
- Fetch real-time weather data using an external API.
- Display temperature and weather conditions.
- Show additional weather details such as humidity and wind speed (if implemented).
- Handle invalid city names and API errors.
- User-friendly interface.

## 🛠️ Technologies Used

- HTML5 – Webpage structure.
- CSS3 – Styling and layout.
- JavaScript (ES6+) – Application functionality.
- Fetch API – Retrieve weather information.
- REST API – External data communication.
- JSON – Process API responses.

## ⚙️ How It Works

1. Enter a city name in the search field.
2. JavaScript captures the user input.
3. Fetch API sends a request to the weather API.
4. The API returns weather information in JSON format.
5. JavaScript processes the response.
6. Weather details are displayed dynamically on the webpage.

## 🚀 How to Run

1. Clone the repository.
2. Open the Weather App folder.
3. Configure the required API key, if applicable.
4. Open `index.html` in your browser or use VS Code Live Server.
5. Enter a city name and explore its weather details.
