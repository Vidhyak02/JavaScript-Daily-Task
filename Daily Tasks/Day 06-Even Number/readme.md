# Day 6 – Even Number

This is my **Day 6 JavaScript Daily Task**, created to practice using JavaScript loops and conditional statements to find even numbers.

## 📌 Task Description

The program takes a limit as input from the user and displays all the **even numbers** from `0` up to the given limit.

## 🛠️ Technologies Used

* HTML5
* JavaScript

## 📂 Project Structure

```text
Day 6 Even Number/
│
├── index.html
├── script.js
└── Output/
    └── output.png
```

## ⚙️ How It Works

1. The user enters a limit.
2. The program checks the numbers from `0` to the given limit.
3. It uses the modulo (`%`) operator to check whether each number is even.
4. The even numbers are displayed as the output.

## 💻 Files

* **index.html** – Contains the webpage structure and input.
* **script.js** – Contains the JavaScript logic to find even numbers.
* **Output** – Contains the screenshot of the program output.
