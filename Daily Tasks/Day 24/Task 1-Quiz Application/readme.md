# Task 1 - Quiz Application

A simple interactive Quiz Application built using HTML and JavaScript. Users can answer multiple-choice questions, receive instant feedback, and view their final score and percentage.

## Features

- Displays multiple-choice questions
- Provides four options for each question
- Checks answers instantly
- Calculates the final score
- Displays the score percentage
- Includes a Restart Quiz option

## Technologies Used

- HTML5
- JavaScript

## Concepts Practiced

- Variables and functions
- `if-else` conditional statements
- Event handling
- DOM manipulation
- Score calculation
- User interaction

## How to Run

1. Download or clone this repository.
2. Open the `index.html` file in a web browser.
3. Select an answer for each question.
4. Click **Next Question** to continue.
5. View your final score and restart the quiz if needed.
