# Positive or Negative Number

This task is a simple JavaScript program used to check whether a given number is **Positive, Negative, or Zero**.

## 🛠️ Technologies Used

* HTML5
* JavaScript

## 📂 Files

* `index.html` – Contains the HTML structure and input interface.
* `script.js` – Contains the JavaScript logic to check the given number.
* `Output/` – Contains the output screenshot of the task.

## 🎯 Objective

The objective of this task is to practice JavaScript **conditional statements** and understand how to check a number based on its value.

## ⚙️ How It Works

1. Enter a number in the input field.
2. The JavaScript program checks the value.
3. It identifies whether the number is:

   * Positive
   * Negative
   * Zero
4. The result is displayed on the webpage.
