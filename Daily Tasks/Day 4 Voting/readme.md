# Day 4 - Voting

## 📌 About the Project

This project is a simple **Voting Eligibility Checker** created using HTML and JavaScript. The main purpose of this task is to check whether a person is eligible to vote based on their age.

The user can enter their age, and the JavaScript program checks the entered value using a conditional statement. Based on the age, it displays the appropriate voting eligibility message.

## 🎯 Objective

The objective of this task is to practice basic JavaScript concepts such as:

* Taking input from the user
* Using variables
* Applying conditional statements
* Comparing values
* Displaying output dynamically
* Understanding basic decision-making logic

## 🛠️ Technologies Used

* **HTML5** – Used to create the basic structure of the webpage.
* **JavaScript** – Used to check the user's age and determine voting eligibility.

## ⚙️ How the Program Works

1. The user enters their age in the input field.
2. The entered value is received by JavaScript.
3. The program checks whether the age is **18 or above**.
4. If the age is 18 or above, a message is displayed stating that the person is **eligible to vote**.
5. If the age is below 18, a message is displayed stating that the person is **not eligible to vote**.
