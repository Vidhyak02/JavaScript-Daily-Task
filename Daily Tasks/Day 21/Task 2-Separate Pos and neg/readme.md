# Task 2 – Separate Positive and Negative Numbers

## 📌 Description
This JavaScript program separates positive numbers, negative numbers, and zeros from an array entered by the user.

The program uses a `for` loop and conditional statements to check each number and place it into the appropriate category. The results are displayed on the webpage.

## 🛠️ Technologies Used
- HTML5
- JavaScript

## 📂 Project Structure
```text
Task 2-Separate Pos and neg/
├── index.html
├── script.js
├── README.md
└── Output/
    └── output.png
```

## ⚙️ How It Works
1. The user enters numbers separated by commas.
2. The program converts the input into an array of numbers.
3. A `for` loop checks each number in the array.
4. Positive numbers are stored in the positive array.
5. Negative numbers are stored in the negative array.
6. Zeros are stored separately in the zero array.
7. The categorized numbers are displayed on the webpage.

## 💻 Example

**Input:**
```text
-2,5,-8,3,7,-1,4,0
```

**Output:**
```text
Negative Numbers: -2, -8, -1
Positive Numbers: 5, 3, 7, 4
Zeros: 0
```

## ✨ Features
- Accepts comma-separated user input.
- Separates positive and negative numbers.
- Identifies zeros separately.
- Uses `for` loops and conditional statements.
- Displays the results dynamically.
- Preserves the original order of numbers in each category.

## ▶️ How to Run
1. Download or clone the repository.
2. Open the `Task 2-Separate Pos and neg` folder.
3. Open `index.html` in a web browser.
4. Enter numbers separated by commas.
5. Click the **Separate** button to view the result.
