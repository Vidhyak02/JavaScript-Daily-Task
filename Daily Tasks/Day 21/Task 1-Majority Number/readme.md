# Task 1 – Find the Majority Number

## 📌 Description
This JavaScript program finds the majority element in an array entered by the user.

A majority element is a number that appears more than half the total number of elements in the array. The program uses nested `for` loops to count the occurrences of each number and identify the majority element.

## 🛠️ Technologies Used
- HTML5
- JavaScript

## 📂 Project Structure
```text
Task 1-Majority Number/
├── index.html
├── script.js
├── README.md
└── Output/
    └── output.png
```

## ⚙️ How It Works
1. The user enters numbers separated by commas.
2. The program converts the input into an array of numbers.
3. Nested `for` loops count the occurrences of each number.
4. The program checks whether a number appears more than half the array length.
5. If a majority element is found, it displays the result.
6. Otherwise, it displays a message indicating that no majority element was found.

## 💻 Example

**Input:**
```text
2,3,2,2,4,2,5
```

**Output:**
```text
Majority Element: 2
```

- Finds the majority element in an array.
- Uses nested `for` loops.
- Counts the occurrences of each number.
- Displays the result dynamically.
- Handles arrays without a majority element.

## ▶️ How to Run
1. Download or clone the repository.
2. Open the `Task 1-Majority Number` folder.
