# Simple Interest Calculator 💰

## 📌 About the Project
The Simple Interest Calculator is a beginner-friendly web application developed using HTML and JavaScript. It calculates the simple interest and total amount based on the principal amount, annual interest rate, and time period entered by the user.

## 🚀 Features
- Accepts principal amount as input
- Takes annual interest rate in percentage
- Accepts time period in years
- Calculates simple interest
- Calculates the total amount including interest
- Validates empty and invalid inputs
- Displays results dynamically

## 🛠️ Technologies Used
- HTML5
- JavaScript

## 💻 Sample Input
| Field | Value |
|---|---:|
| Principal Amount | ₹10,000 |
| Interest Rate | 5% per year |
| Time Period | 2 years |

## 📊 Calculation
**Simple Interest Formula:**

Simple Interest = (Principal × Rate × Time) / 100

- Simple Interest = (₹10,000 × 5 × 2) / 100
- Simple Interest = ₹1,000
- Total Amount = Principal + Simple Interest
- Total Amount = ₹10,000 + ₹1,000 = ₹11,000

## 📤 Sample Output
```text

Interest Amount: ₹1000.00
Total Amount: ₹11000.00
```

## ▶️ How to Run
1. Download or clone the repository.
2. Open the `Task 2-Simple Interest Calculator` folder.
3. Open `index.html` in a web browser.
4. Enter the principal amount, interest rate, and time period.
5. Click the **Calculate Interest** button.
6. View the calculated interest and total amount.
