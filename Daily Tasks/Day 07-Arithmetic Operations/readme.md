**# Day 7 – Arithmetic Operations

## 📌 Description

This task demonstrates basic arithmetic operations using **JavaScript**.

The program performs the following operations on two numbers:

* Addition
* Subtraction
* Multiplication
* Division
* Modulus

## 🛠️ Technologies Used

* HTML
* JavaScript

## 📂 Files

* `index.html` – HTML structure
* `script.js` – JavaScript code for arithmetic operations
* `Output` – Output screenshot

## 💡 Arithmetic Operations

| Operation      | Symbol |
| -------------- | ------ |
| Addition       | `+`    |
| Subtraction    | `-`    |
| Multiplication | `*`    |
| Division       | `/`    |
| Modulus        | `%`    |

## 🎯 Objective

To understand and implement basic arithmetic operators in JavaScript using two numbers.
