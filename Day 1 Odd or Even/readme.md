# JavaScript Daily Task – Day 1

## 🔢 Odd or Even Number

This is my **Day 1 JavaScript Daily Task**, created to practice basic JavaScript concepts.

### 📌 Task Description

The program checks whether a given number is **Odd** or **Even** using JavaScript.

### 🛠️ Technologies Used

* HTML5
* JavaScript

### 📂 Project Structure

```text
Day 1 Odd or Even/

```

### ⚙️ How It Works

1. Enter a number.
2. JavaScript checks the number using the modulus (`%`) operator.
3. If the remainder is `0`, the number is **Even**.
4. Otherwise, the number is **Odd**.
5. The result is displayed on the webpage.

### 💡 Example

```text
Input: 10
Output: Even Number 10
```

```text
Input: 9
Output: Odd Number 9
```
